01 / Capture path

Capture the conversation. Keep the file.

You have a conversation worth keeping. Create a public ChatGPT share and give ChatMD the URL. It captures the visible conversation as deterministic local Markdown on your disk. Revoke the share when you're done. The file stays with you.

  1. T0

    Create a public share

    From the ChatGPT conversation, create a public share. That URL is the required input.

  2. T1

    ChatMD captures the conversation

    From that public share: one HTTP fetch, one deterministic Markdown file, written locally.

  3. T2

    The file is local

    Deterministic Markdown, written to disk under your control.

  4. T3

    Revoke the share

    The public link still exists until you revoke it. The local file is unaffected.

02 / Capture model

Structured share data in. Deterministic Markdown out.

Public share HTML carries the conversation inside its React Router hydration stream. ChatMD reads that structured representation rather than scraping rendered DOM, so message order, roles, and source text come back directly.

  1. 1public share URL
  2. 2structured ChatGPT share data
  3. 3active visible conversation
  4. 4share-visible image bytes
  5. 5normalized model
  6. 6deterministic Markdown
  7. 7validated local capture

03 / Fidelity

The exclusions are the design.

ChatMD captures the reader-visible conversation and nothing else. Execution internals are not evidence of what was said, so they are left out on purpose rather than by accident.

Preserved

  • Exact reader-visible title when present
  • Visible user and assistant messages on the active branch, in order
  • Source-authored Markdown, code fences, tables, links, lists, whitespace
  • Inline citation markers as they appear in the source text
  • Visible file attachments as [File: <filename>] placeholders
  • Supported visible user images as local files with relative links

Intentionally excluded

  • System and tool messages
  • Reasoning, thought, execution, and model-context content
  • Thinking preambles and explicitly hidden messages
  • Tool-directed assistant messages and user system messages
  • UI-only follow-up controls
  • Hidden citation internals

Nothing in the capture path is rewritten by a language model. Text is preserved as the structured share represents it.

04 / Failure semantics

A capture either completes or it does not exist.

Partial captures are the failure mode that matters. A file that looks complete but quietly dropped content is worse than no file, so ChatMD stops instead of guessing.

Fail visible

Unknown visible roles, content types, or multimodal parts stop the run with a clear error instead of being silently dropped. A supported visible image that cannot be preserved fails the capture.

Never overwrite

Existing files are never silently replaced. Collisions keep the original and write a deterministic suffix such as conversation-2.md. Matching image directories use the same suffix.

Persist, then report

CAPTURE COMPLETE prints only after the file is on disk. Failed validation, fetch, parse, or persistence returns a non-zero exit status and no success output.

Security / the share outlives the capture

ChatMD does not revoke the public share.

Capturing a conversation does not un-publish it. Every successful run ends by telling you the link is still live and where to turn it off. Revocation stays a human decision.

05 / Current boundary

What ChatMD deliberately is not.

The scope is narrow because the guarantee is narrow. Everything below is outside the tool today, and the tool is honest about it rather than implying it.

  • ScopeOne public share URL at a time
  • AuthNo ChatGPT login, no private conversations
  • ClipboardZero-argument mode is macOS-native and needs pbpaste
  • FilesFile attachments stay placeholders and are not downloaded
  • ImagesOriginal upload bytes are not recoverable when the share is sanitized
  • ConfigCapture destination is set by CHATMD_CAPTURE_ROOT at runtime
  • KnowledgeNo summarization, tagging, embeddings, RAG, or promotion
  • RevocationShared links are never revoked automatically
  • BundleThe portable bundle contract is specified, not implemented
  • RuntimeNo watcher, no daemon, no GUI, no hosted service

Not a promise of pixel fidelity

ChatMD reconstructs the visible conversation from structured share data. It does not attempt to reproduce ChatGPT's rendered DOM or visual layout, and it does not claim to.

06 / Install

One command to install. One to capture.

The runtime uses the Python standard library. Install once from a checkout, then call chatmd from anywhere.

  1. 1

    Install the local command

    uv tool install .

    Run from a checkout of the repository.

  2. 2

    Capture an explicit share

    chatmd https://chatgpt.com/share/<id>

    One public HTTP(S) share URL, quoted only if the URL needs it.

  3. 3

    Or capture from the clipboard

    chatmd

    macOS only. Used when the clipboard, after trimming whitespace, is exactly one https://chatgpt.com/share/... URL.

Set the capture directory

CHATMD_CAPTURE_ROOT tells ChatMD where captures are saved on this machine.

export CHATMD_CAPTURE_ROOT="/path/to/captures"

Configure it once, then run chatmd from anywhere.
